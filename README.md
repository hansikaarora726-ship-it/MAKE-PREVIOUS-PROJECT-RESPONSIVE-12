# Assignment 12: Make Previous Projects Responsive

## 📌 Project Overview
This project demonstrates responsive web design using HTML and CSS. It features a collection of web development project cards that adjust their layout according to the screen size.

## ✨ Features
- Responsive navigation bar
- Six project cards in a grid layout
- Three-column layout on desktop screens
- Two-column layout on tablet screens
- Single-column layout on mobile screens
- Hover effects on project cards
- Clean and modern user interface
- Responsive design using CSS media queries

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## 📂 Project Structure
```text
Assignment-12/
├── index.html
└── README.md
```

## 🚀 How to Run the Project
1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser.
4. Resize the browser window to test the responsive layout.

## 📱 Responsive Breakpoints
- **Desktop:** Three-column project grid.
- **Tablet:** Two-column project grid.
- **Mobile:** Single-column project grid.
